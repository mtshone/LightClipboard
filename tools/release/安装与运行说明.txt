LightClipboard v1.3.1 —— 安装与运行说明（框架依赖单文件版）
=============================================================

一、这个包里有什么

  说明：本说明是仓库内的发布素材。**v1.3.1 的发布 zip 为两个条目（LightClipboard.exe + README.md），
  不含本文件**；本文件用于需要「说明单独成篇」的分发场景。下面列出的是"说明单独成篇"时的形态。

  · LightClipboard.exe       整个程序（单文件，约 8.33 MB）
  · 安装与运行说明.txt       本文件：运行要求 + 上手步骤
  · README.md                项目说明（偏开发/构建；普通用户看本文件就够）

二、运行要求（重要：本包不含 .NET）
  本包是**框架依赖**版本，电脑上必须先装：
      .NET 10 Desktop Runtime（x64）
      下载：https://dotnet.microsoft.com/download/dotnet/10.0
  请选 "Desktop Runtime"（不是 ASP.NET Core Runtime，也不是 SDK）。
  没装的话双击不会有反应、或提示缺少 .NET。

  系统要求：Windows 10 1809 及以上 / Windows 11（x64）。
  不需要管理员权限（但要粘贴到"以管理员运行"的程序，见第八节）。

三、第一次运行
  1. 建议放在固定目录，例如 D:\Tools\LightClipboard\LightClipboard.exe。
     放在哪里都行 —— 数据不在 exe 旁边（见第七节），移动/删掉 exe 不会丢历史。
  2. 双击运行。第一次会直接弹出面板（之后它会常驻托盘、不再自己冒出来，
     按第三节的方式随时呼出）。程序在后台持续监听剪切板，不占任务栏。
  3. 呼出面板（三种方式任选）：
       · 左键单击托盘图标
       · 全局热键 Ctrl+Shift+V
         （若被其它程序占用，程序会自动降级为 Ctrl+Alt+V；设置页会显示当前生效的热键）
       · Win+V
         （默认"接管"系统自带的剪切板历史：按 Win+V 直接弹出本面板。
           不想要可在「设置」里关掉「Win+V 拦截」。）

四、基本用法
  点卡片             复制该条 + （默认）自动切回刚才的窗口并粘贴，然后收起面板
                     关掉「点击卡片后自动粘贴」就只复制、不粘贴
  拖动卡片           把图片 / 文件拖到资源管理器、Word、微信、QQ 等外部程序
  卡片右侧按钮       收藏（📌）/ 只复制不粘贴（⧉）/ 删除（🗑），悬停卡片才显示
  右键卡片           粘贴到当前窗口 / 复制到剪切板 / 收藏 / 另存为… / 打开所在文件夹 / 删除
  方向键 ↑↓          上下移动当前项；Enter = 粘贴；Delete = 删除
  Esc / 点面板外     收起面板（"失去焦点时自动隐藏"可在设置里关掉）
  Ctrl+F             光标进搜索框；直接打字即按关键词过滤历史

五、多选图片、整批拖出（v1.3.0 新增；拖出顺序 v1.3.1 调整）
  Ctrl + 左键点图片    逐张加入 / 取消选择（选中的卡片有蓝色底纹 + 加粗边框）
                      点文本 / 文件卡片会被拒绝，并提示「多选仅支持图片」
  Shift + 左键        从上次点过的那张图片开始，选一段（区间内的文本 / 文件自动跳过）
  然后拖动**任意一张已选中的图片** → 所有已选图片一次性拖出去，
  落进资源管理器 / 聊天软件的就是多个 PNG 文件。
  拖出顺序（v1.3.1 起）：**用 Ctrl 逐张点选的，就按你的点击顺序**（取消后重新点选的那张排到最后）；
  **只用 Shift 划出一段的，仍按面板里的列表顺序**。Shift 只负责"再选几张"，不会打乱已经点好的顺序。
  页脚会显示「已选 N 张图片」；普通单击卡片、切换筛选、收起面板都会清空多选。

六、设置（顶部「设置」胶囊）
  · 点击卡片后自动粘贴     关掉 = 只复制，自己按 Ctrl+V
  · 失去焦点时自动隐藏     关掉后面板常驻（想把它当"侧边小窗"用就关掉）
  · 始终置顶               面板失焦后被别的置顶窗口压住时自动抬回最上层（需先关掉上面那项）
  · 隐藏延迟（毫秒）       失焦后等多久再收起，50~1000 ms
  · Win+V 拦截             见第三节
  · 暂停监听剪切板         暂停期间复制的内容不入库
  · 开机自动启动
  · 历史记录上限           超出后自动清理最旧的（收藏项始终保留）
  · 外观主题               跟随系统 / 浅色 / 深色

七、数据与隐私
  · 所有内容**只存在本机**，不联网、不上传、无遥测：
        %LocalAppData%\LightClipboard\
            clipboard.db    历史记录（文本 / 图片路径 / 文件路径）
            Images\         截图与图片原图（按内容哈希命名）
            Exports\        拖拽导出用的临时 PNG（7 天后自动清理）
            Logs\           运行日志（保留 14 天）
            settings.json   设置项
  · 想清空历史：面板页脚「清空」；想彻底删干净：退出程序后删掉上面整个目录。
  · 卸载：托盘图标右键 → 退出，然后删除 exe 与上面那个数据目录即可，不写注册表
    （只有「开机自动启动」会在 HKCU\...\Run 下写一项，关掉开关会自行删除）。

八、已知边界
  · 无法自动粘贴到**以管理员身份运行**的程序（Windows 的 UIPI 限制，属系统行为）；
    在那类窗口里按 Win+V 也不会唤起本面板。要长期支持需要额外的提权钩子进程，
    本项目当前作为已知边界记录（见 resources/10-高权限窗口支持决策记录.md）。
  · 首次把图片拖出（或一次拖很多张）时会有一次性导出耗时：程序要先把图片复制到
    Exports\ 目录；选几十张大图时，拖动开始前会有可感知的停顿（本版接受）。
  · 面板宽度被拖到很窄时，卡片文字会自动截断显示。

九、版本与反馈
  本包为 LightClipboard **v1.3.1**（上一版 v1.3.0）。
  每个版本的完整改动与实测记录见仓库 `resources/CHANGELOG.md`。
